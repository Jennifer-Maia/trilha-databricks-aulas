# Estudar com IA

Esta pasta deixa o repositório pronto para você estudar com uma IA que entende o projeto.

| Arquivo | O que tem |
|---|---|
| [`contexto/01_projeto.md`](contexto/01_projeto.md) | O cenário da loja, os módulos e como as pastas estão organizadas |
| [`contexto/02_dados_e_api.md`](contexto/02_dados_e_api.md) | As 4 tabelas, a API do Hugging Face, os limites e os números de referência |
| [`contexto/03_free_edition.md`](contexto/03_free_edition.md) | O que a Free Edition permite e os cuidados do lab |
| [`prompts.md`](prompts.md) | Prompts prontos para estudar, revisar o seu código e montar o portfólio |

## Com o Claude Code

1. Clone o repositório no seu computador: `git clone <url-deste-repositório>`.
2. Entre na pasta e rode `claude`.
3. O Claude lê o [`CLAUDE.md`](../CLAUDE.md) sozinho: ele responde em português, segue as regras do lab e não entrega a solução dos exercícios de cara.

## Com outra IA (ChatGPT, Gemini, Claude no navegador…)

Anexe os três arquivos de `contexto/` e o README da aula no começo da conversa e cole isto:

> Estou estudando a Trilha Databricks da Jornada de Dados. Use os arquivos anexados como contexto. Responda em português, explique o porquê de cada coisa e, nos exercícios, me dê dicas antes de mostrar a solução.

## Um cuidado

A IA pode errar, principalmente sobre recursos do Databricks que mudam rápido. Quando a resposta for sobre a plataforma, peça o link da documentação oficial e confira. Quem decide se o seu código está certo é o notebook de `teste/` da aula.
